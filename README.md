# Real-Time Color Detection and Tracking System

## Problem Statement

Many real-world applications require detecting and tracking specific colors in real-time, but building such systems can be challenging for beginners.

## Objective

To develop a system that detects a selected color from live video and generates a binary mask where the detected color appears white and the rest appears black.

## Description

This project uses OpenCV and Python to track a specific color in real-time. It processes video frames, applies color thresholding in HSV space, and generates a mask output.

## Technologies Used

* Python
* OpenCV
* NumPy
